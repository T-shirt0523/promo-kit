# 定价方法论

## 一、虚拟商品定价的三条前提

1. **没有边际成本。** 多卖一份不增加成本，所以「薄利多销」在虚拟商品上不成立 ——
   销量不会摊薄任何东西，只会摊薄你的毛利。
2. **标价同时是质量信号。** 太便宜会被当成「随便做的东西」，
   而虚拟商品看不见摸不着，买家只能靠价格猜质量。这是它和实物商品最大的区别。
3. **退款与差评成本远高于单价。** 为了几块钱降价引来的低质用户，
   售后成本可能超过这份钱本身。

## 二、三档锚定的原理

```
轻量版  ← 降低决策门槛，接住预算有限的人
标准版  ← 主推，承担绝大部分销量
支持者版 ← 锚点，作用不是卖出去，而是让标准版显得划算
```

**没有高价锚点，标准版会显得贵；有了锚点，标准版就成了「理性选择」。**

倍率参考：

| 档位 | 相对标准版 |
|---|---|
| 轻量版 | 0.5–0.7 倍 |
| 标准版 | 1 倍 |
| 支持者版 | 1.8–2.5 倍 |

支持者版卖的是什么？不是功能，是**情感付费**：开发者支持、可商用授权、优先答疑、
全部后续更新。愿意买的人本来就买，不愿意的也不会被价格劝退。

`scripts/promo_common.py` 的 `build_price_plan()` 实现了这套推导，
产出结果会附完整推导过程，**每一处都可以改**。数字是起点，不是结论。

## 三、心理价位点

优先落在这些数上，避开 `13.7` 这种随手价：

```
3 5 6 8 9 12 15 19 25 29 39 49 59 69 89 99 129 159 199 249 299 399 499 699 999
```

**标准版地板价：¥6。** 低于此价不做。原因见第一节第 2、3 条。

## 四、各渠道抽成与到手价

| 渠道 | 抽成 / 手续费 | 备注 |
|---|---|---|
| 淘宝 / 天猫 | 虚拟类目通常无交易佣金；花呗/信用卡支付手续费约 1% | 需实名 + 保证金 |
| 拼多多 | 交易服务费约 0.6% 起 | 虚拟商品需权属证明（软著最有说服力） |
| 爱发电 / 面包多 | 平台抽成约 6% 起 | 虚拟内容友好，个人可注册 |
| itch.io | 默认 10%，作者可调 | 游戏类友好，需海外收款 |
| 闲鱼 | 个人闲置交易无平台抽成 | 非正规渠道，无仲裁保障 |

> **全部为参考值**，平台规则变动频繁，以平台当前实际规则为准。
> 抽成差异会影响到手价，但不该影响标价 —— 各渠道标价保持一致，否则比价的人会觉得被坑。

## 五、折扣纪律

- **首发可以做「前 N 份 8 折」，但 N 必须是你真的会执行的数字。**
  写「限时」却无限延期，就是虚假宣传。
- **不做 1 折 / 1 元走量。** 低价拉来的是退款率与差评率最高的人群，
  且平台会给店铺打低质标签。
- **涨价要真的涨。** 老用户补差价这件事一次也别做，口碑成本远高于那几块钱。
- **不要跟风降价。** 虚拟商品没有库存压力，价格战只伤毛利。

## 六、什么时候该动价

| 信号 | 动作 |
|---|---|
| 上架两周无人下单，但有人收藏/加购 | **不是价格问题**，是详情页没讲清「买到了能得到什么」 |
| 咨询里反复问同一个问题 | 把答案挪到详情页前两屏，与价格无关 |
| 稳定出单且没人砍价 | 可以上调一档；老用户保持原价 |
| 有人砍价到很低才买 | 别降标价，加一个更便宜的入门档去接住这部分人 |
| 大量「能不能便宜点」但无成交 | 说明人群不对，不是价格不对 |

## 七、常见错误

| 错误 | 后果 |
|---|---|
| 定 1 元/0.1 元走量 | 退款率与差评率飙升，店铺被标低质 |
| 只做一档价 | 没有锚点，买家无法判断「值不值」 |
| SKU 名用「A套餐/B套餐」 | 买家看不懂包含什么，反复追问，转化掉一大截 |
| 标价含平台抽成再加价 | 各渠道标价不一致，比价的人直接走 |
| 长期挂「限时优惠」 | 违规，且用户会等你永远不结束的优惠 |

## 八、SKU 命名的唯一要求

**直接写清楚包含什么。** 不要用代号。

- 好：`标准版 ¥19：完整功能 + 后续小版本更新`
- 差：`B套餐 ¥19`

名字本身就在承担转化工作，别浪费。
