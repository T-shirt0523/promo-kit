# 渠道文案公式

## 总则

**同一段话贴到所有平台上，等于没有文案。**

每个渠道的算法和用户心态都不同：小红书看图和标题、抖音看前 3 秒、B站看过程、
闲鱼看关键词、群里看长度。本 skill 按渠道出差异化版本，不要混用。

**全部文案只允许使用 `facts.json` 里已有的事实。** 不写销量、不写评价、不写奖项、
不写「全网」「第一」。这不是保守，是因为编的数据一旦被戳穿，损失远大于收益。

## 一、小红书

**算法逻辑**：首图决定点击，标题决定搜索，评论决定推流。

| 环节 | 做法 |
|---|---|
| 首图 | 用 `06-宣传图/小红书封面.png`（3:4，文字已排好） |
| 标题 | ≤20 字，一眼看完，末尾最多 1 个 emoji |
| 正文 | 短段，手机上一屏不超过 4 行 |
| 结尾 | **必须提问**，评论量直接决定推流 |
| 标签 | 6–9 个，混合大词与小词 |

**有效句式**（按点击率排序）：

1. `我做了个 XXX` —— 身份认同，用户爱看「一个人做出来」的故事
2. `没用一张素材，我做了 XXX` —— 具体到能验证的冲突
3. `花了两周，我做完了 XXX` —— 成本感

**禁忌**：放二维码、写微信号 → 限流。用「评论区」代替。

## 二、抖音 / 视频号

**算法逻辑**：前 3 秒决定完播，完播决定推流。所以**前 3 秒不要出现产品名**，
先给冲突或结果。

结构（15–20 秒）：

| 时间 | 内容 |
|---|---|
| 0–3 秒 | 钩子。冲突句或结果句，配一个动作画面 |
| 3–8 秒 | 展示。实机画面，切 2–3 个场景，字幕常驻 |
| 8–13 秒 | 证据。切到桌面文件列表 / 属性面板等可核实的画面 |
| 13–18 秒 | 成本与价格 |
| 18–20 秒 | 收尾 CTA |

**要点**：全程竖屏 9:16；字幕必须常驻（多数人静音刷）；
不要写「点击链接购买」——压流量，用「简介里有」。

## 三、B站

**算法逻辑**：B站用户吃「制作过程」。讲你遇到的取舍、踩的坑、为什么这么做，
比展示成品更涨粉。

- 标题 ≤78 字，含检索词（独立游戏 / 自制 / 教程 / 开发日志）
- 简介写详细，B站用户会认真读
- **不要在简介里放外链**，放评论区置顶
- 封面文字 ≤8 字，缩略图才看得清

## 四、闲鱼

**算法逻辑**：纯关键词匹配 + 价格敏感。

- 标题塞满搜索词，30 字内
- 描述分点写清：是什么 / 有什么 / 怎么交付 / 多少钱
- **必写退款规则**，闲鱼纠纷偏买家
- 忌用「卡密」「网盘」等敏感词，改说「付款后发送」
- 砍价要有标准答法：不降标价，改推更便宜的入门档

## 五、群与朋友圈

**算法逻辑**：熟人社群，长文案 = 没人看。

- 群消息**一次说完，只发一次**，不连发、不 @全体成员
- 控制在 3–4 行：是什么 / 一个亮点 / 多少钱 / 怎么拿
- 先问「有人感兴趣吗」再发细节，转化更高且不讨人厌
- 熟人场景不要用营销话术，越朴素越可信

## 六、发布节奏（别一次全平台铺开）

同时发五个渠道，你无法判断哪个有效。

| 时间 | 动作 |
|---|---|
| 第 1 天 | 小红书 + 朋友圈，看点击率 |
| 第 3 天 | B站长视频 |
| 第 7 天 | 抖音短视频 |
| 两周后 | 看哪个渠道有**真实咨询**，其余停掉，集中做那一个 |

判断标准是「有没有人问怎么买」，不是播放量。播放高但没人问，说明渠道人群不对。

## 七、通用禁忌

| 禁忌 | 为什么 |
|---|---|
| 虚构销量/评价/用户数 | 虚假宣传，平台违规，被戳穿损失更大 |
| 「限时」「仅剩 N 份」而不会真的执行 | 同上 |
| 诱导转发、集赞、助力 | 微信生态明确违规，直接封链接 |
| 蹭第三方作品名 | 侵权 + 平台判「傍名牌」 |
| 极限词（最好/第一/独家/顶级） | 《广告法》禁用，可被处罚 |
| 「破解」「盗版」字样 | 平台关键词过滤是无脑匹配的，出现在文案里就可能触发下架 |
