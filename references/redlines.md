# 合规红线

交付前逐条过。`lint_promo.py` 能自动抓前五类，剩下的要人工判断。

## 一、极限词（《广告法》禁用）

```
最、最佳、最好、最优、最强、最低、最高、第一、首选、顶级、极致、
绝无仅有、独一无二、史无前例、前所未有、绝对、100%、全网、全网最低、
国家级、世界级、领导品牌、王牌、独家、万能、包治、无效退款、
免费领、仅此一次、错过不再、销量第一、排名第一、最便宜、史上最、
全球唯一、世界第一、重新定义、颠覆行业、吊打、碾压、无敌、神作、封神
```

**处置**：命中即改，不要「换个说法绕过」—— 判罚看的是实际语义。

## 二、虚构数据

新产品没有销量、没有评价、没有用户数。以下一律不许出现：

- 「已售 N 件」「销量过万」
- 「N 万人选择」「百万玩家」
- 「好评如潮」「好评率 99%」「五星好评」

**理由**：这是虚假宣传，平台可处置，市场监管可处罚。而且一旦被买家发现，
信任崩塌的代价远大于那点收益。

## 三、虚构稀缺

```
限时 N 小时 / 仅剩 N 份 / 最后 N 个名额 / 前 N 名免费 /
涨价在即 / 倒计时抢购 / 今日必抢 / 错过再等 N 天
```

**唯一例外**：你真的会执行。写「前 20 份 8 折」就要真的在前 20 份之后恢复原价。
做不到就不要写 —— 这是本 skill 与「营销话术库」最大的区别：
**用具体事实制造吸引力，而不是用虚假紧迫感。**

## 四、诱导分享（微信生态明确违规）

```
转发 N 个群 / 分享到朋友圈才能 / 集赞 / 助力 / 拉 N 人 / 扫码免费领
```

违规直接封链接，前面所有工作白做。改成一问一答、一对一咨询。

## 五、第三方 IP 名（本项目的硬红线）

**交付物里绝对不能出现任何第三方作品名、角色名、品牌名**，包括：

- 项目源码、注释、README 里的形容方式
- 宣传文案、标题、搜索关键词
- AI 生成提示词
- 「XX同款」「XX风格」「像XX一样」「XX复刻」「XX同人」这类句式

**描述效果就描述效果本身**：写「块状波浪带」而不是「某某风格」，
写「立体屋顶」而不是「某某同款」。`scan_project.py` 会扫项目侧，
`lint_promo.py` 会扫物料侧，两边都要过。

## 六、收款闸门（三道，按顺序卡人）

宣传本身是免费的，**但收钱需要实名**。先确认路径，别做完才发现收不到钱。

| 闸门 | 要求 | 无替代方案？ |
|---|---|---|
| 年龄 | 平台店需年满 18 周岁实名 | 是的。未成年唯一合规路径：**由监护人实名开店，本人做技术提供方**。不要用他人身份证注册，那是违法 |
| 实名 | 身份证 + 手机号 | **手机号无替代方案**，没有就是没有 |
| 收款 | 实名支付宝/微信/银行卡，姓名须与实名一致 | 是的 |

**任一不过时的替代发行路径**（按可执行性排序）：

| 路径 | 门槛 |
|---|---|
| 监护人实名开店 + 本人供货 | 需监护人配合（首选） |
| 闲鱼个人闲置 | 需实名，但门槛低于开店 |
| 爱发电 / 面包多 | 需实名，抽成低，虚拟内容友好 |
| itch.io / Gumroad | 需海外收款能力 |
| 免费发布 + 捐赠 | 无门槛，沉淀作品集 |

给建议时必须先过一遍「年龄 + 手机号 + 收款」三道门槛，
**不要给做不到的方案**，那只是浪费时间。

## 七、AI 产品合规

**自带 Key（BYOK）是唯一干净的路。**

- 自己搭服务器转发 AI 请求 = 成为「生成式 AI 服务提供者」，
  需算法备案 + 内容安全审核。个人办不了，未成年更不行。
- 正确做法：让买家填自己的 baseURL / model / key。产品定性退回「软件」，
  成本与责任完全隔离。
- 不要多账号轮换 key 薅额度：违反上游 ToS，会按支付方式/设备指纹/IP 段一起封。

`scan_project.py` 检测到 AI 相关依赖时会自动警告。

## 八、素材与字体授权

- 项目素材（图、音效、字体）必须**全部自有或程序化生成**；
  有外部素材必须确认授权范围**含商用**。
- 宣传图用的字体必须是可商用的。本 skill 的模板只用系统字体
  （Microsoft YaHei / PingFang SC），正文安全；
  换装饰性字库前先确认授权。
- 详情页/落地页里引用的截图必须是自己产品的实机画面。

## 九、交付时必须说清的话

- 所有平台规则数字（字数限制、保证金、抽成、类目名）都是**参考值**，
  以后台当前实际要求为准。
- 自动生成的内容里，哪些是扫描得到的事实、哪些是推断出的假设值
  （例如平台是假设的），要明确标出来。
