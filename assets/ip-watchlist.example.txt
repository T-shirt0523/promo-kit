# 第三方作品名 / IP 名单
#
# 用法：复制为 ip-watchlist.txt（已在 .gitignore 里），一行一个名字，
#       填你要盯的作品名。命中即判为高危，必须改名。
#
# 为什么仓库里不预置：预置就等于在分发他人 IP 名，不合适。
# 装了姊妹 skill app-listing-kit 的话，会自动复用它的词库，这份可以省。
#
# 改名时不要引他人作品 —— 只描述效果本身。
#   反例：像素风生存玩法，像某某知名作品那样
#   正例：俯视像素地形 + 昼夜循环 + 背包合成
#
# 示例格式（取消注释即可生效）：
# 某个作品名
# AnotherGameTitle
